# Configuration

The central configuration for the frontend site is declared in `docusaurus.config.ts`.

## Site Identity & Build Metadata

- **Title & Tagline**: `title: "Kalidass Journal"`, `tagline: "Field notes from the model layer."`.
- **Target URL**: `url: "https://kalidass.amrit.fyi"`, `baseUrl: "/"`.
- **Tab Icon (Favicon)**: Remote PNG `https://pub-c1d80f0f7327493997a3c1285f43a9ea.r2.dev/amrit_logo.png` declared via `favicon` and `headTags` (icon + apple-touch-icon).
- **Link Checking**: `onBrokenLinks: "throw"` ensures any broken internal routes immediately fail production builds.
- **Future Flags**: `future.v4: true` enables early support for Docusaurus v4 features.

## API Base Resolution & Edge Routing

The frontend enforces relative same-origin routing for all client requests:

1. **Static Configuration**: `customFields.apiBase` is hardcoded to `""` in `docusaurus.config.ts`, ensuring client builds never attempt direct external worker fetches.
2. **Client Initialization**: `src/client-modules/api-base.ts` sets `window.KALIDASS_API_BASE = ""` at boot time.
3. **Runtime Requests**: `src/lib/config.ts` exports `apiUrl(path)`, returning relative `/api/*` URLs (e.g. `/api/articles`).
4. **Edge Interception**: In production, Cloudflare Pages Function `functions/api/[[route]].ts` catches all `/api/*` calls and proxies them directly to `kalidass-journal-worker` using the `JOURNAL_WORKER` Service Binding.

## Plugin Configuration (`kalidassPlugin`)

The custom plugin implements two core lifecycle hooks:

- **`configureWebpack`**: Replaces `devServer.proxy` with a proxy forwarding `/api` requests to `http://127.0.0.1:8787`. Configures host binding to `0.0.0.0` with `allowedHosts` support.
- **`contentLoaded`**: Registers the dynamic client-side route `/story/:slug` mapping directly to `@site/src/components/StoryPage`.

## Theme & CSS Custom Properties

Global styling is defined in `src/css/custom.css`:

- **Color Mode**: Default mode is `dark`, with automatic detection for user OS preferences (`respectPrefersColorScheme: true`).
- **Page Gradient (`--page-gradient`)**:
  - Dark mode: Dark chocolate to charcoal (`#2b1a13` to `#1d1d21`).
  - Light mode: Cream to pure white (`#efe3c8` to `#ffffff`).
- **Hero Accent (`--layer-accent`)**: Colors the hero tagline emphasis (`<em>the model layer.</em>`) — gold in dark mode, vibrant green (`#4e9b47`) in light mode.
- **Card Accent (`--card-accent`) / Story Accent (`--story-accent`)**: Dynamic accent colors injected per article from the article's `accent` hex value.
