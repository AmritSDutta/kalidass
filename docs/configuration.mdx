# Configuration

The central configuration for the frontend site is declared in `docusaurus.config.ts`.

## Site Identity & Build Metadata

- **Title & Tagline**: `title: "Kalidass Journal"`, `tagline: "Field notes from the neural heart."`.
- **Target URL**: `url: "https://kalidass.amrit.fyi"`, `baseUrl: "/"`.
- **Tab Icon (Favicon)**: Remote PNG `https://pub-c1d80f0f7327493997a3c1285f43a9ea.r2.dev/amrit_logo.png` declared via `favicon` and `headTags` (icon + apple-touch-icon).
- **Link Checking**: `onBrokenLinks: "throw"` ensures any broken internal routes immediately fail production builds.
- **Future Flags**: `future.v4: true` enables early support for Docusaurus v4 features.

## Authentication & Environment Fields (`customFields`)

The frontend imports environment variables via `docusaurus.config.ts` into `customFields`:

- **`auth0Domain`**: Tenant domain (`AUTH0_DOMAIN`).
- **`auth0ClientId`**: SPA application client ID (`AUTH0_CLIENT_ID`).
- **`auth0Audience`**: Worker API audience (`AUTH0_AUDIENCE`, default: `https://api.kalidass.amrit.fyi`).
- **`adminEmails`**: Comma-separated list of whitelisted administrator emails (`ADMIN_EMAILS`). Used by the frontend to determine `isSuperuserEligible`.
- **`privateApp`**: When `true`, disables Auth0 entirely in the client bundle and restricts CMS access to standalone `ADMIN_TOKEN`.

## API Base Resolution & Edge Routing

The frontend enforces relative same-origin routing for all client requests:

1. **Static Configuration**: `customFields.apiBase` is hardcoded to `""` in `docusaurus.config.ts`, ensuring client builds never attempt direct external worker fetches.
2. **Client Initialization**: `src/client-modules/api-base.ts` sets `window.KALIDASS_API_BASE = ""` at boot time.
3. **Runtime Requests**: `src/lib/config.ts` exports `apiUrl(path)`, returning relative `/api/*` URLs (e.g. `/api/articles`).
4. **Edge Interception**: In production, Cloudflare Pages Function `functions/api/[[route]].ts` catches all `/api/*` calls and proxies them directly to `kalidass-journal-worker` using the `JOURNAL_WORKER` Service Binding.

## Plugin Configuration (`kalidassPlugin`)

The custom plugin implements two core lifecycle hooks:

- **`configureWebpack`**: Replaces `devServer.proxy` with a proxy forwarding `/api` requests to `http://127.0.0.1:8787`. Configures host binding to `0.0.0.0` with `allowedHosts` support. Additionally registers `@grafana/faro-webpack-plugin` strictly during client compilation (`!isServer`) when source map upload secrets are set.
- **`contentLoaded`**: Registers the dynamic client-side route `/story/:slug*` mapping directly to `@site/src/components/StoryPage`.

## Observability & Client Telemetry

Browser telemetry and source map upload configuration in `docusaurus.config.ts`:

- **`faroCollectorUrl`**: Telemetry ingestion URL (`FARO_COLLECTOR_URL`), or auto-derived from `FARO_ENDPOINT` and `FARO_APP_ID`.
- **`faroAppName`**: Application identifier in Grafana Cloud (`FARO_APP_NAME`, default: `kalidass`).
- **Webpack Source Map Upload**: When all required build variables (`FARO_API_KEY`, `FARO_ENDPOINT`, `FARO_APP_ID`, `FARO_STACK_ID`) are defined, `@grafana/faro-webpack-plugin` is registered strictly during client compilation (`!isServer`) to upload `.js.map` bundles to Grafana Cloud.
- **Client Modules**:
  - `src/client-modules/faro.ts`: Initializes Faro with Core Web Vitals, console error logging, and W3C trace propagation limited to same-origin `/api/` calls.
  - `src/client-modules/hardening.ts`: Cosmetic deterrent blocking devtools shortcuts and context menus in production builds.
  - `src/client-modules/api-base.ts`: Dynamic same-origin `/api` resolver.
  - `src/client-modules/webmcp.ts`: In-browser WebMCP tool definitions and `window.modelContext` registry.

## Theme & CSS Custom Properties

Global styling is defined in `src/css/custom.css`:

- **Primary Brand (`Neel`)**: Configured as `#6366f1` / `#4f46e5` for buttons, active state, and brand accents.
- **Pigment Tokens**: Six CSS pigment variables (`--pigment-neel`, `--pigment-haldi`, `--pigment-sindoor`, `--pigment-gulabi`, `--pigment-mehendi`, `--pigment-aakash`).
- **Rainbow Gradients**: Multi-stop warm and cool rainbow gradients (`--rainbow-gradient-warm`, `--rainbow-gradient-cool`).
- **Color Mode**: Default mode is `dark`, with automatic detection for user OS preferences (`respectPrefersColorScheme: true`).
- **Page Gradient (`--page-gradient`)**:
  - Dark mode: Dark chocolate to charcoal (`#2b1a13` to `#1d1d21`).
  - Light mode: Cream to pure white (`#efe3c8` to `#ffffff`).
- **Card Accent (`--card-accent`) / Story Accent (`--story-accent`)**: Dynamic accent colors injected per article from the article's `accent` hex value.
