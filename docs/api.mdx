# API Reference

The frontend interacts with the Cloudflare Worker API via the client library in `src/lib/api.ts`. All endpoints are resolved through `apiUrl(path)` (see [Architecture](/architecture)).

## Endpoints

| Method | Path | Client Function | Auth Required | Description / Payload |
| --- | --- | --- | --- | --- |
| `GET` | `/api/health` | `getHealth()` | No | Health check — returns `{ ok: true }`. |
| `GET` | `/api/auth/me` | `getAuthMe()` | **Yes** | Returns authenticated user profile `{ user: { email, role, sub, isSuperuserEligible } }`. |
| `POST` | `/api/auth/elevate` | `elevateAuth(adminToken)` | **Yes** | 2-Factor Superuser Elevation. Requires whitelisted email (`ADMIN_EMAILS`) and valid `adminToken` body. Returns `{ ok: true, elevated: true }`. |
| `GET` | `/api/articles` | `listArticles()` | No | Public feed: returns published, non-private articles only. |
| `GET` | `/api/articles?status=draft` | `listArticles("draft")` | **Yes** | Returns draft articles belonging to current author (or all for Super-Admin). |
| `GET` | `/api/articles?status=published` | `listArticles("published")` | **Yes** | Returns published articles (excluding other users' private unlisted articles unless admin). |
| `GET` | `/api/articles?status=all` | `listArticles("all")` | **Yes** | Returns all stored articles accessible to the user. |
| `GET` | `/api/articles/:idOrSlug` | `getArticle(slug)` | Conditional | Returns full article. Drafts and private articles require auth and owner/admin check. |
| `POST` | `/api/articles` | `createArticle(draft)` | **Yes** | Creates a new article stamped with verified `authorEmail`. Body: JSON `ArticleDraft`. Returns created `Article`. |
| `PUT` | `/api/articles/:idOrSlug` | `updateArticle(id, draft)` | **Yes** | Updates an existing article. Enforces ownership (`403 Forbidden` for non-owners). Body: JSON `ArticleDraft`. |
| `DELETE` | `/api/articles/:idOrSlug` | `removeArticle(id)` | **Yes** | Deletes article object from Upstash storage. Enforces ownership (`403 Forbidden` for non-owners). |
| `POST` | `/api/upload` | Direct Upstash SDK | **Yes** | Upstash Blob direct browser upload route. Requires authenticated author or admin. |
| `POST` | `/api/objects` | `uploadObject(file)` | **Yes** | Direct binary upload (`FormData` with `file` field) persisted to Upstash Blob. Returns `{ url, name }`. |
| `GET` | `/api/upload` | Direct Upstash SDK | **Yes** | Upstash Blob direct upload token route (requires `UPSTASH_BLOB_TOKEN` and an authenticated author or admin). |
| `GET` | `/api/blob/:path` | `getMemoryObject` | **Yes** | Serves in-memory blob bytes in dev mode (only active when no `UPSTASH_BLOB_TOKEN` is set). |
| `POST` | `/api/eval/quality` | `evaluateQuality(req)` | **Yes** | Runs AI detection, accuracy, engagement, and safety evaluation. Requires Bearer token. |
| `POST` | `/api/generate` | `generateArticle(req)` | **Yes** | Triggers containerized Upstash Box article authoring run. Requires Bearer token. |
| `POST` | `/api/admin/reset` | Direct request | **Yes** | Flushes the article index to an empty state (Super-Admin only). |
| `POST` | `/api/admin/reindex` | Direct request | **Yes** | Rebuilds `index.json` from stored objects and invalidates all caches (Super-Admin only). |
| `GET` / `POST` | `/api/ai_search_insight` | Direct request | **Yes** | Ad-hoc Google AI Overview lookup for a query (`q`/`query`). Returns `{ ok, query, ai_overview, organic_results, search_metadata }`. |
| `GET` | `/api/articles/:idOrSlug/intel` | `getIntel(slug)` | Conditional | Public read-only intelligence sub-resource (reads from Redis/Blob cache, never spawns Box). |
| `GET` | `/api/articles/:idOrSlug?intelligence=true` | `getArticleWithIntel(slug)` | **Yes** | Compiles or refreshes live SerpApi search intelligence in Upstash Box. Requires author or admin. |
| `GET` | `/api/articles/:idOrSlug/books` | `getArticleBooks(slug)` | Conditional | Public read-only book-suggestion sub-resource (Redis/Blob only, never generates). Gated by draft/private state. |
| `POST` | `/api/articles/:idOrSlug/books` | `triggerArticleBooks(slug)` | **Yes** | Generates/refreshes Amazon book suggestions via SerpApi and the eval scorer. Requires author or admin. |
| `GET` | `/api/articles/:idOrSlug?books=true` | Direct request | **Yes** | Returns the article with an embedded `books_suggestions` payload; honors `refresh=true`. |
| `GET` | `/api/articles/:idOrSlug/research` | `getArticleResearch(slug)` | Conditional | Public read-only arXiv research sub-resource (Redis/Blob only, never generates). Gated by draft/private state. |
| `POST` | `/api/articles/:idOrSlug/research` | `triggerArticleResearch(slug)` | **Yes** | Harvests/refreshes arXiv preprint suggestions and ranks them via the eval scorer. Requires author or admin. |

## Authentication

- **Auth0 Bearer Token**: When logged in via the Auth0 SPA SDK, incoming API requests include an Auth0 Access Token header: `Authorization: Bearer <auth0-jwt>`.
- **Superuser Step-Up Token (`X-Admin-Token`)**: When an eligible author elevates to Super Admin, subsequent requests include `X-Admin-Token: <adminToken>`. The worker validates both email eligibility and token value before granting global administrative privileges.
- **Standalone Admin Token**: Configured on the client via `localStorage.getItem("kalidass-admin-token")` as fallback or for automated M2M publishing.
- **Header**: Included on all mutating requests and privileged list queries as `Authorization: Bearer <token>`.
- **Content Type**: All JSON API requests send `Content-Type: application/json`. File uploads send raw `FormData` without manually overriding the browser-managed multipart boundary.
