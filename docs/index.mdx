# Kalidass Journal Documentation

Field notes from the neural heart. Kalidass Journal is a colorful research publication exploring AI systems: attention architectures, agent workflows, evals, and multimodal plumbing.

The codebase is organized as a combined monorepo containing a Docusaurus 3.10 static UI, an edge Cloudflare Worker REST API, and Upstash Blob storage.

- [Zero Trust Architecture](/zero-trust) — Private isolate edge protection, Service Binding RPC, and token authorization.
