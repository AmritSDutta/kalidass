# Development

## Prerequisites

- **Node.js**: `>=20.0` (validated against Node.js 22).
- **Package Manager**: `npm` is required (`package-lock.json` is checked into version control).

## Scripts Reference

| Command | Description |
| --- | --- |
| `npm run start` | Launches development server on `0.0.0.0:3000` with `/api` proxying to `http://127.0.0.1:8787` |
| `npm run typecheck` | Runs `tsc --noEmit` to validate all TypeScript code |
| `npm run build` | Produces production static output in `build/` |
| `npm run serve` | Serves the production build locally |
| `npm run clear` | Clears `.docusaurus` cache artifacts |

## Docs7 Documentation Site

The documentation site in `docs/` is powered by the `docs7` framework:

```bash
# Preview docs site locally
npx docs7 dev docs --port 3333

# Validate docs site integrity (Mermaid, frontmatter, trees, links)
node scripts/validate_docs.mjs docs
```

## Toolchain Guidelines

- **Sources are `.ts/.tsx` Only**: Never commit compiled `.js` files in `src/`. Sibling `.js` files will be resolved first by Webpack and cause runtime browser crashes.
- **Windows Verification**: On Windows, PowerShell may require `npm.cmd run typecheck`. Run `typecheck` + `start` for verification, as dynamic route paths (`/story/:slug`) cause Windows filesystem errors during static build generation.
- **DOM Guards**: Browser-specific global objects (`window`, `localStorage`) must be guarded with `typeof window !== "undefined"` or `ExecutionEnvironment.canUseDOM`.
