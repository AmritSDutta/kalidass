# Environment Variables

The worker reads configuration from two sources: **Cloudflare secrets** (set via `wrangler secret put`) and **`[vars]`** in `wrangler.toml`. Locally, secrets are loaded from `.dev.vars`.

## Variable Reference

| Variable | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `UPSTASH_BLOB_TOKEN` | Secret | For persistence | *(absent)* | Upstash Blob read/write token. When absent, the worker falls back to in-memory storage and articles do not persist across restarts. |
| `ADMIN_TOKEN` | Secret | Optional | *(absent)* | Legacy/M2M Bearer token for Super-Admin and AI Agent automated publishing. Write endpoints require valid Auth0 JWT or `ADMIN_TOKEN`. |
| `UPSTASH_BOX_API_KEY` | Secret | For Box features | *(absent)* | Upstash Box API key required for autonomous article generation (`/api/generate`) and Python intelligence runs. |
| `SERPAPI_API_KEY` | Secret | For intelligence | *(absent)* | SerpApi key (`SERPAPI_API_KEY` or `SERP_API_KEY`) used to extract Google search intelligence and AI Overviews. |
| `UPSTASH_REDIS_REST_URL` | Var / Secret | For caching | *(absent)* | Upstash Redis REST endpoint URL. When absent, the worker falls back to an in-memory Map cache. |
| `UPSTASH_REDIS_REST_TOKEN` | Secret | For caching | *(absent)* | Upstash Redis REST authentication token. |
| `EVAL_PROVIDER` | Var / Secret | Optional | `"jev"` | Active quality evaluation provider (`"jev"`, `"clef"`, or `"heuristic"`). Cascades on failure. |
| `JEV_API_KEY` | Secret | For Jev eval | *(absent)* | TypeSafe AI Jev decision API key used by the quality & safety evaluation pipeline. |
| `OPENAI_API_KEY` | Secret | For Box generator | *(absent)* | OpenAI API key passed to Upstash Box containers for agent content authoring and DALL-E hero art. |
| `TAVILY_API_KEY` | Secret | For Box generator | *(absent)* | Tavily API key passed to Upstash Box containers for deep research search grounding. |
| `AUTH0_DOMAIN` | Var / Secret | Optional | `""` | Auth0 tenant domain (e.g. `dev-xxx.us.auth0.com`) used for JWKS remote signature verification. |
| `AUTH0_AUDIENCE` | Var (`wrangler.toml`) | Optional | `"https://api.kalidass.amrit.fyi"` | Auth0 API identifier (audience) for validating JWT claims. |
| `ADMIN_EMAILS` | Var / Secret | Optional | `""` | Comma-separated list of email addresses granted Super-Admin permissions (`role: "admin"`). |
| `ROOT_BUCKET` | Var (`wrangler.toml`) | Optional | `"kalidass"` | Root folder prefix inside Upstash Blob (e.g. `kalidass/index.json`, `kalidass/articles/`). |
| `CORS_ORIGIN` | Var (`wrangler.toml`) | Yes | `"https://kalidass.amrit.fyi"` | Value of the `Access-Control-Allow-Origin` response header matching the Cloudflare Pages domain. |

## Frontend Build Environment Variables

| Variable | Scope | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `PRIVATE_APP` | Cloudflare Pages / Build | Optional | `"false"` | When `"true"`, disables Auth0 login UI and operates Studio exclusively with `ADMIN_TOKEN`. |
| `AUTH0_DOMAIN` | Cloudflare Pages / Build | Optional | `""` | Auth0 tenant domain passed into frontend build (`customFields.auth0Domain`). |
| `AUTH0_CLIENT_ID` | Cloudflare Pages / Build | Optional | `""` | Auth0 SPA Client ID passed into frontend build (`customFields.auth0ClientId`). |
| `AUTH0_AUDIENCE` | Cloudflare Pages / Build | Optional | `"https://api.kalidass.amrit.fyi"` | Auth0 API Audience identifier (`customFields.auth0Audience`). |

## Effect on Storage Mode

| `UPSTASH_BLOB_TOKEN` | Storage Mode | Persistence |
| --- | --- | --- |
| Set | Upstash Blob | Articles and media persist durably across worker restarts and redeployments. |
| Absent | In-Memory Fallback | Articles are held in worker memory and reset on reload (dev mode). |

## Local Development (`.dev.vars`)

Copy `.dev.vars.example` to `.dev.vars` and populate as needed:

```bash
cp .dev.vars.example .dev.vars
```

```text
UPSTASH_BLOB_TOKEN=replace-with-upstash-blob-token
ADMIN_TOKEN=
ROOT_BUCKET=kalidass
```

> [!IMPORTANT]
> `.dev.vars` is listed in `.gitignore` and must never be committed. It is read exclusively by `wrangler dev` and is never deployed.

## Setting Production Secrets

Use the `wrangler secret put` command to store secrets in Cloudflare's encrypted secret store:

```bash
npx wrangler secret put UPSTASH_BLOB_TOKEN
# Paste your token when prompted — input is hidden

npx wrangler secret put ADMIN_TOKEN
# Enter a secure passphrase or secret Bearer token
```

Secrets are bound to the named worker (`kalidass-journal-worker`) and are available on `env` in the `fetch` handler.
