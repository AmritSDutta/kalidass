# Studio

The Studio interface is located at `/admin` (`src/pages/admin.tsx`). It provides an integrated CMS for writing, editing, organizing, and publishing articles directly into Upstash Blob storage via the Cloudflare Worker API.

## Authentication, Identity & Sudo Elevation

Access to Studio requires authentication via **Auth0** (or developer unlock with `ADMIN_TOKEN`):

- **Auth0 Login (`@auth0/auth0-spa-js`)**: Authors log in with their email and credentials via Auth0 Universal Login. Login preserves the user's active page via `appState.returnTo` without forcing an unwanted redirect to `/admin`.
- **Top Navbar Profile Dropdown (`AuthNavbarItem.tsx`)**: All user identity information, role indicators, and authentication controls are consolidated in the top navigation bar:
  - **Unauthenticated**: Displays a clean **Sign In** action.
  - **Authenticated Author**: Displays avatar/initials, full name, email, and `Author` badge.
  - **Super Admin**: Displays `Super Admin` badge, `🛡️ Superuser Active` status indicator, and an **Exit Superuser** action.
- **2-Factor Superuser Elevation**:
  - **Factor 1 (Identity Whitelist)**: The `⚡ Login as Superuser` button is only shown if the author's email is present in `ADMIN_EMAILS` (or contains the Auth0 `admin` role). Unauthorized users cannot elevate and API calls to `/api/auth/elevate` return `403 Forbidden`.
  - **Factor 2 (Passphrase)**: Submitting the valid `ADMIN_TOKEN` passphrase in the elevation modal elevates the session to `Super Admin` (`role: "admin"`).
- **Exit Superuser & Instant Privilege Drop**:
  - Clicking **Exit Superuser** immediately drops session privileges back to `role: "author"`, removing `X-Admin-Token` from storage and hiding `Edit in studio →` links across non-owned stories without requiring a page refresh.
- **Sign Out**:
  - Clicking **Sign out** flushes all storage keys, resets auth state, triggers Auth0 logout, and redirects to `/`.

## Private App Mode (`PRIVATE_APP=true`)

When building the frontend with `PRIVATE_APP=true` (set in Cloudflare Pages build environment or `.env`):

- **Auth0 UI Disabled**: The *"Sign in with Auth0"* button is completely hidden from the Studio lock screen, and the prompt reverts to *"enter admin token"*.
- **No Auth0 Client**: The Auth0 SPA client is never instantiated, and no dynamic token provider is registered with `api.ts`.
- **Admin-Only Unlock**: The Studio operates strictly through `kalidass-admin-token` from `localStorage` as a single-operator publication.
- **Worker Invariants Unchanged**: The Cloudflare Worker edge API remains the authoritative security boundary. Public reader pages (`/`, `/magazine`, `/story/:slug`) remain accessible to everyone without authentication.

## Tab Modes

The Studio features four operational modes accessible via top tab navigation or deep linked via the `?mode=` URL query parameter:

### 1. Compose Mode (`?mode=compose`)

The primary writing environment:
- **New Articles**: Displays action buttons for **Save draft** (`published: false`) and **Publish** (`published: true`). Pre-fills author name and avatar from the user's profile.
- **Existing Articles**: Loaded via `?edit=<slug>`, displaying an **Update** action that maintains the existing publication state and ID while allowing slug and content changes.
- **Form Controls**:
  - **Title**: Story headline. Auto-generates the URL slug as you type until manually edited.
  - **URL Slug**: Editable path slug displayed with `/story/` prefix. Auto-slugified with hyphenation, lowercase conversion, and punctuation removal.
  - **Author Email (Read-Only)**: Inferred automatically from the user's login credentials. Cannot be forged or edited by the client.
  - **Subtitle & Excerpt**: Subheadings and summary deck text.
  - **Author Name & Role**: Display byline credentials.
  - **Tags**: Comma-separated categorization tags.
  - **Accent Swatch**: 6-color swatch picker matching the publication pigment tokens (`ACCENTS`).
  - **Featured Flag**: Highlights the story in the dedicated homepage Featured section.
- **Visibility Toggles**:
  - **Private (Unlisted)**: Defaults to checked (`true`). Excludes the article from `/` and `/magazine` public feeds and restricts direct `/story/:slug` reads to the author or an admin (anonymous requests return `404`).
  - **AI Generated**: Defaults to unchecked (`false`). Displays the `AI` badge on cards and headers when enabled.
- **Block Editor**: Dynamic block list supporting `paragraph`, `heading`, `quote`, `image`, `video`, and `code` (with language selector, file title, and monospace editor) blocks with re-ordering, updating, and removal capabilities.

### 2. Drafts Mode (`?mode=drafts`)

- Calls `listArticles("draft")` (requires Bearer token).
- **Edge-Enforced Isolation**: The Cloudflare Worker returns only drafts authored by the current user (`authorEmail === user.email`). Super-Admins see all drafts across all authors.
- Features client-side search across title, subtitle, author email, and tags.
- Table rows provide one-click **Edit** (loads in Compose), **Publish** (sets `published: true`), and **Delete** actions.

### 3. Published Mode (`?mode=published`)

- Calls `listArticles("published")`.
- **Edge-Enforced Isolation**: Authors see all public published articles plus their own private articles. Other authors' private articles are completely filtered out at the edge.
- Highlights user's own articles with a `My Story` badge.
- Edit and Delete buttons are enabled only for articles owned by the logged-in author (or for Super-Admins).

### 4. Delete Mode (`?mode=delete`)

- Calls `listArticles("all")` to display removable articles.
- Authors can only delete their own articles; Super-Admins can delete any article.
- Protected by a browser confirmation dialog and worker-enforced 403 ownership check.

## Editor Sidebar Analysis Panels

When editing an already-saved article, the right-hand editor sidebar renders the analysis and compilation cards alongside the live outline:

- **Quality & Safety (`Article Heuristics`)**: The **Run Quality Audit** action evaluates the draft for AI-generation probability, systems rigor, engagement, and the pre-submit safety gate (see [Evaluation](/evaluation)).
- **Live Outline (`Heading Analysis`)**: Section count, total words, estimated read time, and a clickable document-structure outline with per-heading word counts.
- **AI Intelligence (`Search Grounding`)**: **⚡ Compile AI Intel** / **↻ Refresh AI Intel** harvests a SerpApi dossier (AI Overview, Knowledge Graph, People Also Ask) via `POST /api/articles/:id/intel`, with an inline drawer to preview it (see [Reading Experience](/reading-experience)).
- **Book Suggestions (`Curated Literature`)**: **⚡ Find Book Suggestions** / **↻ Refresh Suggestions** ranks Amazon literature via `POST /api/articles/:id/books` (see [Books Suggestions](/books-suggestions)).
- **Research Papers (`Academic Research`)**: **⚡ Find Research Papers** / **↻ Refresh Research** harvests and ranks arXiv preprints via `POST /api/articles/:id/research` (see [Research Suggestions](/research-suggestions)).

The intelligence, books, and research cards only render once the article has an id, and each shows a status badge with the item count and the scoring provider before expanding its read-only results drawer.

## Media Upload Integration

File upload controls are embedded directly in the form fields:
- **Cover Image Upload** (`accept="image/*"`): Uploads image and updates `draft.coverImage` with live thumbnail preview.
- **Lead Video Upload** (`accept="video/*"`): Uploads video file and updates `draft.videoUrl`.
- **Block Uploads**: Image and video blocks feature dedicated file upload pickers.

Uploads are executed through `uploadObject()` in `src/lib/api.ts`, sending raw binary buffers to `POST /api/objects` with Bearer auth, which the Cloudflare Worker persists directly to Upstash Blob.
