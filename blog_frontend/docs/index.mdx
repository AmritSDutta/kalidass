# Amrit Journal Documentation

Field notes from the model layer. Amrit Journal is a static Docusaurus research magazine designed for reading AI-systems essays and managing publications via an integrated admin studio.

Articles and media assets are stored in Upstash Blob via a Cloudflare Worker API. Content is loaded dynamically at runtime in the client rather than compiled from static Markdown files.

## Documentation Index

- [Architecture](/architecture) — Client routing, dynamic route plugins, API-base resolution, and proxy architecture.
- [AI Agent Publishing](/agent-publishing) — Server-to-server publishing specification for automated agents and background workflows.

- [Studio](/studio) — Web-based content creation, drafting, multi-block editing, and deletion interface.
- [Media and Uploads](/media-uploads) — Video player resolution (YouTube, Vimeo, direct MP4) and Upstash Blob uploads.

- [Configuration](/configuration) — `docusaurus.config.ts`, custom fields, client modules, and CSS variables.
- [Deployment](/deployment) — Production setup for Cloudflare Pages, Cloudflare Workers, and Upstash Blob.
- [Development](/development) — Local setup, toolchain requirements, scripts, and verification procedures.
- [Learnings](/learnings) — Architectural discoveries, CommonJS/ESM build conflicts, and Windows platform nuances.

## Quickstart

```bash
npm install
npm run start
```

The frontend development server runs on `http://0.0.0.0:3000` and proxies `/api` calls to `http://127.0.0.1:8787`.
